## 一句话
2026 年现象级项目(416,541⭐/104,143 fork,GitHub 历史前几名):一个 MCP 让 Agent 逆向一切——从 App 行为到原生二进制,MIT。

## 触发场景
- 研究"Agent 桥接专业工具"架构模式时(REA 不自己逆向,而是调度 Hopper/Ghidra/IDA/JADX/binwalk 并整理证据链返回——该模式可复用到任何领域)
- 想搞懂某个 App/二进制/模型文件/协议的实现时,直接拿它来问自己的 agent
- 学多 agent 形态打包时(一源四形态:npm 包 + .claude-plugin + .codex-plugin + skill,35+ 目标类型的静态解析器全内置免依赖)
- 给 lhg-secure 补充能力:审计闭源组件时做成分核实(打包器/依赖/签名/构建信息)

## 要点
- 工作流:Agent 经 MCP 调用 REA 检查目标 → 返回"结论+证据"(伪代码/符号/调用引用/未知项)→ Agent 追问、解释行为、或写出并测试复刻实现
- 能力矩阵 35+ 目标类型:原生二进制(桥 Hopper/Ghidra/IDA/Kuna)、Go/Rust 内嵌构建信息、PE 证书/导入表、ELF notes、内核模块、Erlang BEAM、WASM、EVM 合约、Android APK(JADX/apktool/adb 真机)、Flutter、Unity IL2CPP(免 Unity)、Godot PCK、.NET、PyInstaller、Electron/JS 应用、网站观察、HAR/pcap 抓包、Apple IPS 崩溃、固件 binwalk、SQLite、信号录制、进程 PTY 捕获;AI 特化:GGUF/safetensors 模型工件元数据、CUDA/HIP GPU 代码对象(PTX)
- 静态解析器全部免依赖内置(不装 Unity/Godot/Go 也能解析其产物);部分目标调用外部工具(pwntools/WABT/tshark/JADX)
- 工程形态:npm `rea-agents`(`npx rea-agents setup`)、skills.sh 收录、.agents/.claude-plugin/.codex-plugin 三目录一源、35 个 CI workflow、TypeScript 136MB、多语言 README(22 种)
